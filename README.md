# Synthetic Observational Treatment Effects

An end-to-end R workflow for estimating the average treatment effect (ATE) of two treatment strategies from observational longitudinal data.

**Rendered analysis report:**  
[https://carlos-orellana-heredia.github.io/obs-treatment-effects/](https://carlos-orellana-heredia.github.io/obs-treatment-effects/)

## Why this project exists

This repository demonstrates a reproducible causal-inference workflow: defining a target estimand, simulating treatment-selection bias, estimating propensity-score weights, checking overlap and covariate balance, and estimating longitudinal and time-to-event outcomes.

All data generated by this repository are synthetic. They were designed to illustrate the analytical structure of a comparative-effectiveness study; they contain no patient-level data, confidential data, or study results from an external source.

## Analytical question

Among eligible individuals with a time-zero baseline assessment, what is the average effect of **Strategy A** versus **Strategy B** on event-free recovery over 12 months?

The primary estimand is the ATE at 12 months:

$$
\mathrm{ATE}_{365} =
\mathbb{E}\left[Y^{(A)}(365) - Y^{(B)}(365)\right]
$$

The simulation has a known data-generating mechanism, so the analysis can compare an unadjusted estimate, an IPTW estimate, and the known simulation truth.

## Workflow

1. `R/00_packages.R` checks the required packages.
2. `R/01_simulate_data.R` creates the synthetic baseline, treatment, longitudinal, and survival datasets.
3. `R/02_describe_cohort.R` creates a descriptive cohort summary.
4. `R/03_estimate_iptw.R` estimates stabilized ATE weights and writes balance diagnostics.
5. `R/04_estimate_longitudinal_ate.R` estimates weighted marginal outcome trajectories with GEE.
6. `R/05_analyze_time_to_event.R` fits weighted Kaplan-Meier and Cox analyses.
7. `R/06_sensitivity_analyses.R` compares untrimmed and trimmed weights.

Run the complete workflow with:

```r
source("run_all.R")
```
All `ggplot2` figures use `theme_classic()`.

## Repository layout

```text
R/        Analysis scripts

```

Synthetic data and generated outputs are included to make the workflow immediately inspectable. All files can be reproduced by running the analysis scripts with the documented random seed.

## Causal assumptions

The illustrative analysis assumes:

- consistency of the observed outcome with the assigned strategy;
- conditional exchangeability given measured baseline covariates;
- positivity of both strategies across relevant covariate profiles; and
- appropriately specified propensity-score and outcome models.

These assumptions are built into the simulation for teaching and validation purposes. In applied observational research, they require substantive justification and diagnostic assessment; no weighting method can address unmeasured confounding.

## Scope and limitations

This is a portfolio case study, not a clinical recommendation or validation of either strategy. It deliberately uses a compact set of pre-treatment variables. Procedural or post-assignment variables are not included in the propensity-score model because they may lie on the causal pathway.
